# 科研零基础阶梯式导师

`research-learning-tutor` 是一个中文科研学习技能。它按先修知识排课，用白话、类比、图解和分步例题讲清概念，再用随堂题检查理解并衔接下一课。论文、专利或项目可以作为案例；导师会区分已核对的资料、通用知识、教学假设和待核推断。

适用主题：钙钛矿、化学与材料科学、太阳能电池、实验与表征、Python、机器学习、扩散模型、科研读写。

## 安装

下载本仓库 ZIP 并解压。把直接包含 `SKILL.md` 和 `references/` 的文件夹命名为 `research-learning-tutor`，复制到用户目录的 `.agents/skills/`（所有项目），或项目内的 `.agents/skills/`（仅该项目）。技能由 Codex 加载，无需运行服务。
