# 课程路线

选择与目标吻合的主线；按需要接入其他主线的前置课，不要求所有学科从头学完。每个箭头是一组可细拆的小课，末尾任务用于检查能否把知识用起来。

| 主线 | 建议顺序 | 结课任务 |
|---|---|---|
| 化学与材料科学 | 原子、离子与键 → 组成与化学计量 → 晶格、晶胞、晶粒 → 缺陷与材料性质 | 用晶胞图解释组成、排列与缺陷的区别 |
| 钙钛矿材料 | 晶胞和电荷入门 → 理想 ABX₃ 结构和位点 → 成分与真实结构 → 薄膜成核、生长与缺陷 → 稳定性 | 读一张结构图，区分位点、成分和理想化假设 |
| 太阳能电池 | 光、能量、电压与电流 → 半导体、电子与空穴 → 光生载流子和复合 → 器件层叠 → J–V、效率和测试条件 | 从给定曲线读出关键参数并解释比较条件 |
| 实验与表征 | 问题、变量、对照、重复与误差 → 样品及测量条件 → XRD、SEM、UV–Vis、PL 等按需分课 → 交叉验证 | 针对一个材料问题选方法，写出各自能和不能回答什么 |
| Python | 值、类型和变量 → 列表、循环和判断 → 函数 → 读取表格、处理缺失值、画图 | 从小表格算一个统计量，并解释输出或报错 |
| 机器学习 | 特征与标签 → 训练、验证和测试 → 回归或分类基线 → 指标 → 过拟合与数据泄漏 → 误差分析 | 为小数据集设计评估；讨论同批次样品跨集合的影响 |
| 扩散模型 | 随机变量与噪声 → 分布和条件 → 神经网络训练直觉 → 逐步加噪 → 学习反向去噪和采样 → 条件生成与评价 | 用示意图区分训练目标和采样步骤，说明生成结果为何还需验证 |
| 科研读写 | 问题与主张 → 图表、方法和结果 → 证据与限制 → 用自己的话复述并标引 → 用证据组织段落 → 修改 | 逐句标出一段讨论的主张、证据和适用范围 |

综合路线示例：想读懂“用生成模型做钙钛矿研究”的论文，可先选“晶胞与位点”“数据表与特征”“噪声与条件生成”三条短支线，再回到论文的输入、输出、验证证据。学习者只想看懂一张图时，只补看懂该图所需的知识。

实验教学从原理、读图和数据判断入手；把模型预测、观测结果与因果结论分开。科研写作练习可使用明确标记的教学材料；没有真实证据的结果、引用或方法细节留待补充。
